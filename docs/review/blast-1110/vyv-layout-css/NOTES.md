Laptop-size layout and controller focus fixes for the menu: every picture in before/ has a partner of the same name in after/, taken at the size in its name from the base build and from this branch.

With a controller, every dialog (Settings, the tip jar, the terminal chips, the Open-it-here card, the offline card, a pack's gallery) now shows the amber ring on the button it is on, and a pack's "contents" opens a visible panel on desktop instead of an invisible one (the pad-* pictures).

At 1280x720 and the other laptop sizes the CONTACT heading no longer runs into the top bar, all thirteen cartridges and the "13 of 13" count stay on screen, a long Sites status line drops under its button instead of running over the preview, and the Wallpapers pack's game row stays on one line.

The top bar no longer jumps sideways when you leave Games (the back arrow sits in the left margin) and "music on" stays on one line; Settings uses the site's warm dark colours instead of navy.

At 1920x1080 the only other change is SHITBOX's two-line kindline no longer ending on one word, and the phone pictures (phone-*) are the same apart from Settings' colours.
